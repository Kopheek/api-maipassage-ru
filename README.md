# API Маёвский цитатник
API «Маёвский цитатник» — REST-сервис с коллекцией цитат преподавателей Московского авиационного института (МАИ). Публичные эндпоинты доступны без авторизации, админские — защищены API-ключом.

https://img.shields.io/badge/python-3.x-blue
https://img.shields.io/badge/flask-3.0.3-green

# О проекте
Проект представляет собой лёгкое API для хранения, поиска и выдачи цитат преподавателей МАИ. Данные хранятся в JSON-файле, кэшируются в памяти и могут быть перезагружены «на лету» без перезапуска сервера.

# Возможности
- 📚 Получение списка цитат с фильтрацией:

    - q — поиск по тексту цитаты (регистронезависимый);

    - author — фильтр по автору (подстрока);

    - subject — точное совпадение по предмету;

    - limit — ограничение количества результатов (по умолчанию 50).

- 🎲 Случайная цитата — отличный вариант для ботов и виджетов.

- 🔍 Поиск одной цитаты по ID.

- 📂 Списки уникальных авторов и предметов.

- 🔄 Админский эндпоинт перезагрузки данных (POST /v2/admin/reload) с защитой по X-API-Key.

- 📑 Автодокументация Swagger UI (Flasgger) — доступна по /v2/docs.

- 🩺 Health-check для мониторинга.

- 🌐 CORS включён — можно дёргать API прямо из браузера.

- 🇷🇺 Корректный вывод кириллицы.

# Установка
```bash
git clone https://github.com/Kopheek/api-maipassage-ru.git
cd api-maipassage-ru
pip install -r requirements.txt
```

# Настройка окружения
Создайте файл `.env` в корне проекта:

```env
SECRET_KEY=your-secret-key
ADMIN_API_KEY=your-admin-api-key
```
> ⚠️ Если ADMIN_API_KEY не задан, защищённые эндпоинты вернут 500 — доступ не откроется «всем желающим».

# Запуск
### Режим разработки
```bash
python app.py
```
Сервер поднимется на http://127.0.0.1:5000.

### Продакшн (Gunicorn)
```bash
gunicorn "api:create_app()" --bind 0.0.0.0:8000 --workers 4
```
# Основные эндпоинты
| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/v2/health` | Проверка состояния API |
| `GET` | `/v2/quotes` | Список цитат с фильтрами |
| `GET` | `/v2/quotes/<id>` | Цитата по ID |
| `GET` | `/v2/quotes/random` | Случайная цитата |
| `GET` | `/v2/subjects` | Список предметов |
| `GET` | `/v2/authors` | Список авторов |
| `POST` | `/v2/admin/reload` | 🔒 Перечитать файл цитат |
| `GET` | `/v2/docs` | Swagger UI |
| `GET` | `/v2/apispec.json` | OpenAPI-спецификация |

### Примеры запросов
```bash
# Все цитаты (первые 10)
curl "http://127.0.0.1:5000/v2/quotes?limit=10"

# Поиск по тексту
curl "http://127.0.0.1:5000/v2/quotes?q=ёжик"

# Фильтр по автору
curl "http://127.0.0.1:5000/v2/quotes?author=Данилина"

# Случайная цитата
curl "http://127.0.0.1:5000/v2/quotes/random"

# Перезагрузка данных (только с ключом)
curl -X POST "http://127.0.0.1:5000/v2/admin/reload" \
     -H "X-API-Key: your-admin-api-key"
```
### Пример ответа
```json
{
  "count": 1,
  "results": [
    {
      "id": 3,
      "author": "Данилина",
      "subject": "Математический анализ",
      "text": "Это даже Ёжику понятно, Ёжики, вам понятно?"
    }
  ]
}
```

# Безопасность
Админский ключ сравнивается через `secrets.compare_digest` — защита от timing-атак.

Ключ передаётся в заголовке `X-API-Key`.

Если ключ не задан в окружении — эндпоинт возвращает `500`, а не открывает доступ.
